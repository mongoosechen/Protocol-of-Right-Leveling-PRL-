# Protocol of Right-Leveling

The Protocol of Right-Leveling (PRL) is an operator-based method for detecting questions that begin too late—after consequential conditions, positions, or forms of authority have already been removed from view.

## Central question

What has a question already decided before the respondent begins to answer it?

PRL examines how an inquiry:

- selects its entry point;
- assigns positions and answerability;
- removes difference-making conditions;
- determines whether refusal can appear as information;
- constructs the object available for investigation.

## Working paper

**When a Question Begins Too Late: The Protocol of Right-Leveling and the Positional Architecture of Technological Ethics**

[Read the paper in Markdown](paper/when-a-question-begins-too-late.md)  

The paper introduces PRL as a method and applies it to the Trolley Problem. The case shows how a question may multiply respondents while preserving a single centrally authored command position.

## The five PRL operators

1. Entry-level test
2. Position map
3. Difference-maker recovery
4. Refusal-legibility test
5. Research-object reconstruction
